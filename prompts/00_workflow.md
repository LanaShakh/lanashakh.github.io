# Content Pipeline: все варианты

## Общий workflow (мировая практика 2026)

Доминирующий подход в индустрии: **Multi-Pass Generation**

```
Исследование → Структура → Черновик → Редактура → Фактчек → Публикация
     ↑                                    ↑              ↑
  AI + веб-поиск                    AI + человек     человек + its-ai.org
```

91% контент-агентств используют этот подход. Время на статью: ~1 час (вместо 3-4 часов полностью вручную).

---

## Вариант 1: AI-агенты (один бот = весь pipeline)

Один бот выполняет все шаги последовательно в одном чате. Не нужно копировать между чатами.

### Gemini Gem (рекомендуемый)

**Плюсы:**
- 1M контекст — не потеряет информацию
- Встроенный Google Search для research
- Интеграция с Google Docs

**Настройка:**
1. gemini.google.com → Gem Manager → Create Gem
2. Вставь инструкции из `gemini_gem_instructions.md`
3. Загрузи `style_examples.md` (после заполнения)

**Как работать:**
```
ТЫ: "Напиши статью о best AI detectors for teachers 2026.
      Keywords: AI detector, best AI detector, AI detector for teachers"

GEM: [Шаг 1] Ищет источники → показывает список
ТЫ: "Источник 3 убери, остальные ок"

GEM: [Шаг 2] Показывает структуру статьи
ТЫ: "Добавь секцию про цены, в остальном ок"

GEM: [Шаг 3] Пишет статью с цитатами
ТЫ: "edit"

GEM: [Шаг 4] Анализирует AI-паттерны, переписывает
ТЫ: "Предложения 3, 7 и 15 помечены в its-ai.org"

GEM: [Шаг 5] Переписывает флагнутые предложения → финал
```

**Файл:** `gemini_gem_instructions.md`

---

### Custom GPT (ChatGPT)

**Плюсы:**
- Встроенный web browsing
- GPT-5 агентный режим (шаги выполняются автоматически)
- GPT Store для сохранения и шеринга

**Настройка:**
1. chatgpt.com → Explore GPTs → Create
2. Configure → вставь инструкции из `custom_gpt_instructions.md`
3. Включи Web Browsing
4. Загрузи `style_examples.md` в Knowledge

**Файл:** `custom_gpt_instructions.md`

---

### Claude Project

**Плюсы:**
- 200K контекст
- Лучшее качество long-form текста среди всех LLM
- Отличная редактура (Шаг 4)

**Минус:**
- Нет веб-поиска. Источники нужно предоставить вручную.

**Обходной путь:** Используй Gemini Gem или ChatGPT для Шага 1 (research), затем работай в Claude Project для Шагов 2-5.

**Настройка:**
1. claude.ai → Projects → New Project
2. Set custom instructions → вставь из `claude_project_instructions.md`
3. Загрузи `style_examples.md` + свои лучшие статьи в Knowledge

**Файл:** `claude_project_instructions.md`

### Сравнение агентов

| Критерий | Gemini Gem | Custom GPT | Claude Project |
|----------|-----------|------------|----------------|
| Веб-поиск | Google Search | Web Browsing | Нет |
| Контекст | 1M | 128K | 200K |
| Качество текста | Хорошее | Хорошее | Лучшее |
| Качество редактуры | Среднее | Среднее | Лучшее |
| Все 5 шагов в одном чате | Да | Да | Шаги 2-5 (без research) |
| Цена | $19.99/мес | $20/мес | $20/мес |
| Стабильность | Средняя | Высокая | Высокая |

**Мой совет:** Начни с **Gemini Gem** (самый полный — research + writing в одном месте). Если качество текста не устроит, переключись на **Claude Project** для шагов 2-5.

## Общие советы

### 1. Заполни style_examples.md
Скопируй 2-3 абзаца из своих лучших статей на its-ai.org/blog в файл `style_examples.md`. Это **самая эффективная техника** для улучшения качества — AI будет копировать твой стиль.

### 2. Батчинг для 10+ статей/мес
- День 1: Прогони research для 4-5 тем (быстрый шаг)
- День 2: Прогони writing для всех тем
- День 3-4: Editing + проверка через its-ai.org

### 3. Проверка через its-ai.org
Это единственный шаг, который НЕЛЬЗЯ автоматизировать (нет API). Выдели на него основное время. Heatmap показывает какие предложения "фонят" — перепиши только их.

### 4. Что улучшает "человечность"
- Добавляй свой личный опыт и мнение в 2-3 местах
- Начинай абзацы неожиданно: вопросом, числом, коротким утверждением
- После 3 длинных предложений — одно короткое
- Замени абстрактные утверждения конкретными примерами
