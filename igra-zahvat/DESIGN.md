## 1. Что это за игра
Аркадная стратегия «потоков» (в духе state.io / Galcon). Ты — «диспетчер»:
башни производят юнитов, ты **тянешь связи** от своих башен к другим, и юниты
бегут по связям — усиливать свои башни или атаковать чужие. Захватываешь всё поле.

## 2. Ядро (петля)
```
БАШНЯ (производит юнитов) → юниты идут ТОЛЬКО по связям, которые нарисовал игрок
     → приходят в цель:  своя башня → +усиление   |   чужая → −атака (0 защитников → захват)
```
Юниты **никогда** не двигаются случайно — только по связям игрока.

## 3. Башня — стержень (уровни 1→4)
Уровень задаёт всю структуру:

| Ур. | Связей (стрелок) | Ёмкость | Производство | Как получить |
|-----|------------------|---------|--------------|--------------|
| L1  | 1                | 30      | ×1           | старт |
| L2  | 2                | 60      | ×2           | **авто** при переполнении + **выбор КЛАССА** |
| L3  | 3                | 90      | ×3           | **вложение** + **ветка внутри класса** |
| L4  | 4                | 120     | ×4 + синергия| **вложение** + **эпик класса** |

- **Связей = уровню башни** (маяк даёт +1). НЕ зависит от числа войск (это был баг — чиним).
- **Пороги уровня** (`levelNeed`): L1→L2 = **25** (занижен, чтобы класс открывался рано и башня
  доходила до него САМА в покое); L2→L3 = 60, L3→L4 = 90 (= ёмкость, значит нужны подкрепления
  из других своих башен). Ёмкость по-прежнему 30×уровень.
- **Пока из башни идёт связь — гарнизон не растёт** (всё производство уходит в юнитов). Это by design.
- Выбор класса на L2: меню **открывается само** (разово за бой, не во время туториала),
  плюс башня помечена пульсирующей ⭐ до выбора.
- **Рост уровня — гибрид:** L1→L2 автоматически; L2→L3 и L3→L4 — осознанное вложение
  (накопил гарнизон → жмёшь «прокачать», тратится ~половина ёмкости).
- **Ловушка снята:** башня прогрессирует к апгрейду всегда; под нагрузкой (льёшь войска)
  медленнее, в покое — быстрее. Точные числа — на плейтест.

## 4. Классы юнитов (стиль = роль). Одна башня = один класс
Выбор класса на L2. Классы — это и внешний стиль, и боевая роль. Все 4 живут в игре
одновременно (разные башни качаешь по-разному).

| Класс | Роль | Поведение (черновик, тюним на тесте) |
|-------|------|--------------------------------------|
| 🛡 **Пузатики** | Защита | живучие, крепко держат/обороняют башни |
| ⚔ **Рыцари**   | Атака  | высокий урон по врагу |
| 🚜 **Механизмы**| Осада  | сильны против башен, но медленные |
| ✨ **Духи**     | Поддержка / Завод | быстрые; ускоряют/усиливают свои потоки и производство |

- **Юниты БЕЗ личных уровней** — их определяет роль (класс).
- На L2 выбираешь **роль**, на L3 — **ветку внутри роли** (не второй класс!), на L4 — **эпик**.
- «Эконом» из старой версии переименован → **Завод** (⚙ Производство), логично уходит к Духам/ветке.

## 5. Захват
Захватил чужую башню → её класс **сбрасывается в «рекрут»** (базовый слабый юнит),
класс выбираешь заново на L2. Чисто и понятно.

## 6. Визуал / читаемость (демка: look-demo-classes)
- **Башня в цвет команды:** тон всей модели умножением на осветлённый цвет команды +
  **колпак-крыша цвета команды** поверх «красной» kit-крыши (нейтрал — серый).
  Красная команда идеальна; у синей остаётся лёгкий красный поясок тела —
  добить правкой текстуры-атласа при желании.
- **Класс читается тремя способами:** силуэт юнита + значок класса над башней +
  цвет-акцент цоколя. Цвет тела юнита = команда.
- **L3 — герб/флаг прямо на башню** (видно вложение). *(планово)*
- Связи — **тонкая линия** (не толстая стрелка); поток показывают идущие юниты.
- Юниты — с анимацией (шаг / качение гусениц / парение), лицом по ходу.

## 7. Что уже сделано в игре (на момент документа)
- Тонкие связи вместо толстых стрелок; юниты крупнее.
- Башни: каменный цоколь + контактная тень + флаг команды (нейтралам/маякам — нет).
- Земля: плавная тональная фактура (vertex-цвет поверх цвета биома).
- **БАЗА классов (собрана, на тесте):**
  - `linkCap` = уровню башни (маяк +1) — связи больше не «плавают» от числа войск.
  - Спецы заменены на **4 класса** (поле `n.spec` = `chibi|knight|mech|spirit`, null = рекрут):
    🛡 chibi-защита (входящий урон ×0.6) · ⚔ knight-атака (урон ×1.4, быстрые) ·
    🚜 mech-осада (урон ×1.8, медленные) · ✨ spirit-Завод (произв. ×1.5, быстрые).
  - Выбор класса — меню на L2 (4 кнопки). Захват → `spec=null` (рекрут).
  - Юниты рисуются по классу (`makeSoldierMesh`) с анимацией (шаг/танк/парение).
  - Башни тонируются в цвет команды + колпак-крыша команды; цоколь — акцент класса
    (`CLASS_ACCENT`); башня перестраивается при смене класса (`n.cr`).
- **Пока НЕ сделано (следующий шаг):** гибрид-прокачка с «вложением» (сейчас уровень
  растёт авто при переполнении, как раньше). Числа классов — черновые, под плейтест.

## 8. Идеи «на потом» (парковка — прототипировать ПОСЛЕ базы)
- 🔮 **Алтарь духов** — особый узел карты (не на всех картах). Кто держит — мощный буст
  производства всем своим башням. Тяжело взять (регенерирующая охрана / только осада /
  «просыпается» в середине матча). «Король горы», меняет ход партии.
- 🔁 **Прокачка сортировкой** (в духе loop/bus-паззлов) — периодические заказы «отвести
  нужный тип в нужную башню за таймер» → успел → ранг/статы юнитов растут (заслуженно скиллом).
- 🐉 **Дракон** — эпик-ультимейт L4 одного из путей (поджигает башню, юниты разбегаются).
- 🔥 **Факелы / ночной режим** — отдельный «сложный режим», детали позже.
