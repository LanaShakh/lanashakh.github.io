# Инструкция для Claude (прочитай перед любой работой в этом репозитории)

## Что это за репозиторий

Личный сайт Светланы (lana) — **lanashakh.github.io**, GitHub Pages. Он живёт
двумя жизнями одновременно, и их нельзя путать:

1. **Портфолио** — `index.html` в корне (контент-менеджер и SEO-копирайтер,
   RU/EN). Плюс `assets/`, `cv/`, `og.png`, `robots.txt`, `sitemap.xml` и
   страницы-редиректы (`about.html`, `cases.html` и т.п.).
   ⚠️ **Не трогай эти файлы, если задача явно не про портфолио.**
2. **Мобильные HTML-игры** — каждая в своей папке `igra-*` (и `skazhi-pokazhi`).
   Игры публикуются на самом сайте и готовятся к Яндекс Играм.
   Основная работа сейчас идёт здесь.

## Железные правила для игр (выстраданы, не нарушай)

1. **Одна игра = один файл** `igra-*/index.html`: vanilla JS + canvas/DOM,
   всё инлайн, работает офлайн, никаких CDN, внешних шрифтов и запросов.
2. **Весь UI на русском.** Тексты короткие, тёплые, без канцелярита.
3. **Мобайл прежде всего**: портрет, управление одним пальцем,
   `touch-action:none`, обёртка `#wrap` с фиксированным аспектом
   (на десктопе — колонка по центру со скруглением и тенью). Смотри
   `igra-pesok/index.html` как эталон структуры (экраны меню/победы,
   звёзды, HUD).
4. **Никакой спешки в логических играх** — ни таймеров, ни исчезающих
   кнопок. В аркадах игроку всегда дают осмотреться до старта
   (в «Песочке» — кнопка «Сыпать» + отсчёт 3-2-1 + замедление времени,
   пока палец на экране). Владелица репозитория очень чувствительна
   к этому — уже была жёсткая обратная связь.
5. **Красота — требование, а не бонус.** У каждой игры свой цельный
   визуальный мир (собор, дзен-сад, мастерская часовщика), объёмный свет
   и тени, продуманная палитра. «Работает, но выглядит сыро» — не сдаётся.
6. **SDK Яндекс Игр** — в `<head>` заглушка
   `<script src="/sdk.js" onerror="void 0"></script>` и guarded
   `YaGames.init` внизу (вне платформы 404 — это нормально, игра
   обязана работать и без SDK).
7. **Прогресс и настройки** — в `localStorage` (`<игра>_stars`,
   `<игра>_snd`). Звук — только WebAudio-синтез, без аудиофайлов.

## Как проверять (обязательно перед коммитом)

Headless-браузер уже настроен: Chromium лежит в `/opt/pw-browsers/chromium`,
пакет `playwright-core` можно поставить npm-ом в scratchpad. Рецепт:

```js
const { chromium } = require('playwright-core');
const browser = await chromium.launch({ executablePath: '/opt/pw-browsers/chromium', args: ['--no-sandbox'] });
const page = await browser.newPage({ viewport: { width: 390, height: 780 }, hasTouch: true, isMobile: true });
await page.goto('file:///home/user/lanashakh.github.io/igra-<имя>/index.html');
```

Минимум проверок: 0 `pageerror`/console error (404 заглушки `/sdk.js` —
ожидаем, игнорируй); пройти уровень через тестовые хуки игры; скриншоты
меню и геймплея — и **посмотреть их глазами**, сломанный вид = не готово.
Тестовые хуки уже есть: «Витраж» — `__startLevel/__applySolution/__isWin`,
«Сад камней» — `__move(dir)`, «Часовщик» — `__solve()/__state()`.

## Git и публикация

- Работай в ветке, которую тебе назначили; коммиты с понятными русскими
  сообщениями; пуш — `git push -u origin <ветка>`.
- Мерж в `main` = публикация: GitHub Pages сразу отдаёт игру по адресу
  `lanashakh.github.io/igra-<имя>/`. Поэтому в `main` — только проверенное.
- PR создавай только если попросили.
