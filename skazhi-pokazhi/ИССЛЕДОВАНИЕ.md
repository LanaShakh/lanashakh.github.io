# Исследование: методики и приложения для развития речи у детей с алалией/ЗПР

**Дата:** июнь 2026
**Для проекта:** «Скажи-Покажи» — развивающие карточки с озвучкой
**Аудитория:** дети ~5–10 лет с сенсомоторной алалией / ЗПР (нарушение и понимания, и собственной речи)

> Международные термины-аналоги: receptive-expressive language disorder, developmental language disorder (DLD), childhood apraxia of speech (CAS), late talkers, minimally verbal children.

---

## 🎯 Главные выводы (если читать только это)

1. **AAC и карточки с озвучкой НЕ тормозят речь — чаще запускают её.** Это разбивает главный страх родителей. В обзорах 87% детей улучшили устную речь, ни одно исследование не показало ухудшения. Есть кейс: ребёнок-«молчун» с ~5 слов за занятие вышел на 196+ слов за 4 занятия с поддержкой AAC. → Это наш главный аргумент на лендинге.

2. **Режим «Покажи» (слушаем → выбираем картинку) — самый доказательный механизм.** Это *retrieval practice* (активное припоминание), сильнейший приём в литературе. Мы угадали с ядром продукта.

3. **Авто-оценка произношения через ИИ — тупик для этой аудитории.** Технически (распознавание не работает на нечёткой речи) и клинически (бинарный вердикт противоречит методике). Оценивать должен человек. → Поэтому в «Скажи» делаем запись+сравнение, а не авто-судью.

4. **Ниша подтверждена и почти пустая:** аккуратное, недорогое, **русскоязычное** приложение, где родитель собирает **свои карточки (фото + слова + запись голоса)**, объединяющее **понимание + называние**, с лёгким прогрессом. Топовые западные приложения ($250–300) — без русского; русские — бесплатные, но без полировки и глубины.

## ЧАСТЬ 1. Доказательные методики

### 1.1. Развитие ПОНИМАНИЯ речи (рецептивная)

**Что работает (с источниками):**

- **Прямая работа над языком (словарь, грамматика) эффективнее «тренировки процессов».** Прямые языковые интервенции дают положительный результат в ~75% случаев против ~38% у тренировки «обработки». → https://pmc.ncbi.nlm.nih.gov/articles/PMC9620681/
- **Тренажёры «слухового/темпового восприятия» (типа Fast ForWord) НЕ улучшают понимание речи.** «Нет убедительных доказательств эффективности». → https://pmc.ncbi.nlm.nih.gov/articles/PMC9620681/
- **Детям с DLD нужно в 2–3 раза больше повторов.** При 10 показах слова догоняют норму, при 3 — нет. → https://pmc.ncbi.nlm.nih.gov/articles/PMC8126157/
- **Ориентир дозировки: ~36 показов на слово** — порог надёжного усвоения. → https://pubs.asha.org/doi/10.1044/2019_LSHSS-VOIA-18-0131
- **Активное припоминание (выбор слова) сильнее пассивного повтора** — в среднем +1.59 слова при той же дозе (p<.001). → https://pmc.ncbi.nlm.nih.gov/articles/PMC8126157/
- **Разнесённые повторы лучше «подряд».** Схема с промежуточными словами между повторами одного слова бьёт повтор «в лоб». → https://pmc.ncbi.nlm.nih.gov/articles/PMC8126157/
- **Дети с DLD выигрывают от разнесённого припоминания БОЛЬШЕ нормы**, эффект держится до недели. → https://pmc.ncbi.nlm.nih.gov/articles/PMC8126157/
- **Безошибочное обучение (errorless learning) лучше метода проб и ошибок** и меньше зависит от рабочей памяти. → https://pubmed.ncbi.nlm.nih.gov/23201155/
- **Сильнее всего работает мультимодальная (звук+картинка) визуальная поддержка**; обучение значению И звуку слова вместе даёт средний эффект (d≈0.74). → https://pmc.ncbi.nlm.nih.gov/articles/PMC9620681/

**ВЫВОД для «Покажи»:** мы делаем правильно. Усилить: разносить повторы (не одно слово подряд), целиться в ~30–40 показов на слово как порог «освоено», начинать с 2 контрастных картинок (безошибочно) → потом сложнее, возвращать «выученные» слова через дни.

### 1.2. Развитие ЭКСПРЕССИВНОЙ речи (называние, имитация)

- **Enhanced Milieu Teaching (EMT) — хорошо доказан** (мета-анализ, 46 исследований, 1590 детей). → https://pubmed.ncbi.nlm.nih.gov/39666897/
- **Лучший эффект — когда занимается РОДИТЕЛЬ (и/или вместе со специалистом), а не специалист один.** → https://pubmed.ncbi.nlm.nih.gov/39666897/
- **Conversational recasting (переформулирование) — доказательный приём:** не отвергать ответ, а повторно дать правильный образец. → https://pubs.asha.org/doi/10.1044/2025_JSLHR-24-00885
- **Focused stimulation:** много повторов ОДНОЙ цели без требования произнести. → https://pubs.asha.org/doi/abs/10.1044/2020_LSHSS-19-00069
- **AAC + натуралистичные методы дают больше речи, чем методы в одиночку** (для малоговорящих). → https://link.springer.com/article/10.1007/s10803-024-06382-7
- **Для CAS (апраксия) — методы на основе моторного научения (DTTC, ReST):** массированная практика сначала, потом вперемешку; обратная связь — редкая/отложенная. → https://childapraxiatreatment.org/evidence-based-treatment-for-cas/
- **Hanen «It Takes Two to Talk»: меняет поведение родителя, но влияние на речь ребёнка — смешанное.** → https://pmc.ncbi.nlm.nih.gov/articles/PMC8345947/
- **⚠️ Gestalt Language Processing / NLA — НЕ доказательный метод**, эмпирических подтверждений нет. Не строить продукт на нём и не заявлять как «доказательное». → https://pubmed.ncbi.nlm.nih.gov/38784430/

**ВЫВОД для «Скажи»:**
- Всегда давать **аудио-образец** (модель → ребёнок повторяет).
- **Не отвергать**, а повторно показывать образец (recast).
- **Обратная связь редкая, не на каждой попытке** — бинарный авто-вердикт вреден.
- Каркас по слогам (CV → CVCV → длиннее), кнопка «медленно».
- Делать **режим для родителя** (совместность усиливает эффект).
- Принимать жест/приближённое произнесение, не только идеальное.

### 1.3. AAC и PECS

- **AAC = всё, что дополняет/заменяет речь** (картинки, карточки, говорящие приложения, жесты). → https://www.asha.org/practice-portal/professional-issues/augmentative-and-alternative-communication/
- **«AAC не мешает развитию речи на ранних этапах»** — позиция ASHA. → https://www.asha.org/practice/early-intervention-provider-support/augmentative-and-alternative-communication-in-early-intervention/
- **87% участников улучшили устную речь, снижения речи — ни в одном исследовании.** → https://apps.asha.org/EvidenceMaps/Articles/ArticleSummary/48f75b29-1b15-4e0b-8e36-f65092d0d145
- **PECS — 6 фаз** (обмен картинкой → дистанция → различение картинок → фраза «Я хочу» → ответ на вопрос → комментирование). → https://pecsusa.com/pecs/
- **Мета-анализ PECS (2010):** прирост коммуникации малый-умеренный, прирост речи малый (речь — не основная цель PECS). → https://pubmed.ncbi.nlm.nih.gov/20181849/
- **Свежий мета-анализ (34 RCT, ~2343 детей):** PECS эффективен для коммуникации. → https://www.sciencedirect.com/science/article/abs/pii/S0891422225002744
- **Ядро (core) vs периферия (fringe):** ~200–400 частотных слов = ~80% речи; периферия (существительные, темы) — личная, её и надо давать настраивать. → https://www.assistiveware.com/learn-aac/using-symbols-and-text-for-communication
- **Нет «требований готовности» к AAC** — поле отказалось от «модели кандидата». Можно начинать рано, не «в последнюю очередь». → https://www.healthychildren.org/English/health-issues/conditions/developmental-disabilities/Pages/augmentative-and-alternative-communication-for-children.aspx
- **Кейс:** late-talker с ~5 слов/занятие → 196+ слов за 4 занятия с AAC. → https://pmc.ncbi.nlm.nih.gov/articles/PMC7494562/

**ВЫВОД:** смело добавлять AAC-черты. Заголовок для родителей: «AAC не останавливает речь — чаще её запускает». Обещать **функциональную коммуникацию**, речь — как вероятный бонус (честно). Дать ядро частотных слов + быстрый доступ к своим. Никаких «уровней допуска».

## ЧАСТЬ 3. Ниша и позиционирование

**Найденные дыры рынка (подтверждены жалобами):**

1. **Подписочная усталость + оплата за устройство.** → Дать разовую или семейную оплату.
2. **Нельзя добавить свои слова/фото/голос** в детских увлекательных приложениях (это есть только во взрослых или дорогом AAC). → Наш «родитель-соавтор».
3. **Русский язык с глубиной** почти отсутствует. → Русский-first + потенциально билингва RU/EN для диаспоры.
4. **Малоговорящие дети выпадают** между словарными приложениями и полным AAC. → Наш сегмент «первые слова + понимание».
5. **Понимание + называние вместе** — почти никто не совмещает. → У нас оба режима.
6. **Дёшево + есть прогресс** одновременно — редкость. → Лёгкий трекинг.

**Самая защищённая ниша (наш курс):**
> Доступное (разовая/семейная оплата), русскоязычное приложение для малыша/начинающего говорить, где родитель собирает **свои карточки с фото, словами и записью голоса**, объединяющее **понимание + называние**, с лёгким прогрессом. Это бьёт сразу по цене, персонализации, языку и тяжести — ни один игрок не закрывает всё это вместе.

## ЧАСТЬ 4. Что встроить в продукт (чек-лист принципов)

**Режим «Покажи» (понимание):**
- [x] выбор картинки = активное припоминание (уже есть)
- [ ] разносить повторы слова (не подряд)
- [ ] ~30–40 показов на слово до статуса «освоено»
- [ ] безошибочный старт: 2 контрастные картинки → усложнять
- [ ] возврат выученных слов через дни (интервальное повторение)

**Режим «Скажи» (называние) — без ИИ:**
- [ ] всегда аудио-образец, по слогам + «медленно»
- [ ] 🎙️ запись голоса ребёнка + сравнение «образец ↔ попытка»
- [ ] оценка — мягкая шкала, планку задаёт родитель (не бинар, не авто-судья)
- [ ] recast: не «неверно», а повтор образца

**Общее:**
- [x] свои карточки + фото (уже есть) — добавить запись голоса
- [ ] стартовое ядро частотных слов
- [ ] режим для родителя/специалиста
- [ ] лёгкий прогресс-отчёт
- [ ] никаких медицинских заявлений (позиционирование «развивающее»)
